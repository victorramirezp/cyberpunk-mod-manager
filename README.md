# CYBERMOD 2077 // Modular Catalog & Virtual Atelier Hub

> Aplicación web avanzada para la catalogación modular, gestión y orden de carga de mods de **Cyberpunk 2077**. Diseñada con estética Night City (paleta oscura `#08090d`, amarillo Kiroshi `#fcee0a`, cian `#00f0ff`, rojo Arasaka `#ff003c` y morado Neón `#b537f2`), 100% autocontenida en `index.html` y desplegada en **GitHub Pages**.

---

## 🛍️ Integración Virtual Atelier Hub

La aplicación incluye un módulo dedicado de compras in-game conectado con los mods de ropa y tiendas virtuales:
- **Zenitex Military Tactical**: Indumentaria táctica y militar para Mas V.
- **Veegee Atelier**: Sets casuales, trajes Netrunner de combate y joyería.
- **PeachuXL Atelier**: Conjuntos estilizados y ropa femenina contemporánea.
- **Nola Dreamer Boutique**: Ropa de fiesta, abrigo de Evelyn Parker y lencería After Dark.
- **HeRa Atelier**: Bodysuits, tacones altos y moda urbana para Fem V y Mas V.
- **Atomiic Store**: Ropa de invierno, ropa deportiva urbana y accesorios.
- **Axellysse / Meluminary**: Diseños de alta costura y bañadores.

## 🏎️ Concesionario Virtual & Superdeportivos

Nuevo hub de **Vehículos** con soporte para coches deportivos de alto rendimiento vinculados con el Virtual Car Dealer (`MOD_012` y `MOD_030`).
